# Florida Man Times

The wildest true stories from the Sunshine State. Live at https://floridamantimes.com (GitHub Pages).

## Add a story
1. Open `stories.py` and add a new entry at the top of `STORIES`.
2. Run `python3 build.py`.
3. Commit and push. GitHub Pages publishes it in a minute or two.

Every story is rewritten in our own words from a real news report and links to its source.
